# 結友亭 共通保存の公開前設定

このコードは準備済みですが、Googleへの配置と実機接続はまだです。現在の公開アプリは端末内保存です。

1. 所有者のGoogleアカウントで Google Apps Script の新規プロジェクトを作り、Code.gs と appsscript.json を配置する。プロジェクト設定でマニフェストの表示を有効にし、同梱の明示スコープを使う。
2. プロジェクト設定のスクリプトプロパティに OWNER_PIN（勇水の数字4桁）を必要に応じて設定する。省略時は1111。暗証番号はチャットや公開コードに記載しない。
3. エディタで initializeOwner を1回実行し、「このアプリで使用する特定のファイル」の権限を確認して承認する。全ファイルへの権限が表示されたら承認せず、マニフェストの反映を確認する。既存のスプレッドシートは使わない。共通データの専用JSONファイルを非公開で新規作成する。OWNER_PINプロパティは消去される。
4. ウェブアプリとしてデプロイする。「実行するユーザー：自分」「アクセス：全員」。会員の認証はAPI内で行う。管理用エディタやDriveファイルは公開しない。
5. /execで終わるURLを cloud-config.json の endpoint に設定し、provider を apps-script、enabled を true に変更する。
6. 勇水でログインし、管理者ページで端末内の予定・記録・出欠を共通保存へ移す。会員登録・初期暗証番号配布・管理者追加を行う。
7. 別のスマホでログインし、出欠の更新、権限、再読込、LINE経由からChrome/Safariでの起動を実機確認する。

PINの誤入力5回で登録名ごとに15分間ロック。PINはサーバーの秘密鍵と会員ごとのsaltによるHMACで保存。認証セッションは12時間で失効し、停止・PIN変更で無効化する。最初の管理者は勇水のみ。管理者の追加は勇水のみ。過去の予定を記録へ移す操作は管理者全員が行える。管理者権限と出欠の本人判定はサーバーでも検証する。

4桁は1万通りなので、銀行口座・住所などの機微情報をこのアプリに保存しない。初期PINは1111。会員は自分で変更でき、1111のままでも利用できる。

Google Apps Scriptの無料利用枠を利用する構成。実際の割り当て制限はGoogle側の条件に従う。Cloud Functionsや有料プランへの変更は行わない。Firebase接続は既存構成を残し、自動では切り替えない。

## 最小権限への変更

drive.file（このアプリで作成・明示的に選択したファイルのみ）と script.external_request（Google Drive APIから専用JSONを読む通信）の2スコープだけを指定。DriveAppは使用しない。通信先はコードに固定したGoogleのAPIのみ。任意ファイルのIDはクライアントから受け取らず、サーバーのDB_FILE_IDのみ使用する。ファイル一覧・共有変更・削除のAPIは呼ばない。drive.fileは「1ファイルだけ」というスコープではないが、本実装は専用ファイル以外を選択・参照する機能を持たない。

Google側へのコードとマニフェストの反映、同意画面の確認、実機接続は別途必要。広い旧権限を過去に許可済みなら、Googleアカウントの接続管理で旧権限を取り消してから再承認する。既存DB_FILE_IDは削除・再初期化しない。

## 既存公開版に出欠の代行登録を反映する

既存プロジェクトの `Code.gs` を更新して保存し、「デプロイ」→「デプロイを管理」で現在のウェブアプリを編集する。バージョンに「新バージョン」を選択し、同じデプロイを更新する。既存の実行ユーザー、アクセス設定、公開 URL、スクリプトプロパティを使う。既存環境では `initializeOwner` の実行は不要。

更新後、既存の `/exec` の GET 応答に `"attendanceProxy":true` があることを確認する。この確認はデータを書き込まない。代行登録ボタンは、対応済みサーバーが管理者セッションに機能を通知した場合だけ表示する。

同じ更新で、稽古詳細からの当日転記にも対応する。既存 `/exec` の GET 応答に `"rehearsalArchiveToday":true` があれば対応版。転記と予定の移動は、同じ保存処理で実行される。

# 通知登録と受信確認

案内リンク（公開反映後）:
https://yuyutei-rakugo.github.io/performance-manager/#notifications

リンクから通知設定を開く。未ログインの場合は高座名でログインしてから設定へ進む。「通知を受け取る」から端末の許可を求め、登録成功後に本人の端末へテスト送信する。iPhone/iPadはホーム画面から開く案内を表示する。

テスト通知を押して開き、同じ会員と登録端末で認証できた時点で、開いた日時を記録する。送信受付と開封確認は別表示。管理者設定の「通知の配信状況」で、高座名ごとの未登録・登録済み・最新テスト結果・開いた日時を確認する。確認情報が管理者に表示されることは登録画面で説明する。

開封はテスト通知のみ。通常の公演通知や普段の閲覧履歴は記録しない。古いテスト通知、別会員、異なる端末では開封確認を保存しない。通知を開いても通信やログインが完了しなければ開封未確認のままになる。

## 反映

先に Apps Script の Code.gs と Push.gs を更新し、既存ウェブアプリのデプロイを新しいバージョンへ更新する。URL・通知秘密鍵・PUSH_MODE・既存トリガーは変更不要。その後フロントエンドを公開する。

実機確認: 案内リンク → ログイン → 通知登録 → テスト通知到着 → 通知を押す → 設定完了表示 → 管理者画面で該当高座名の開封日時を確認する。
